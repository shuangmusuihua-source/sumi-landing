# sumi landing

Independent product landing page for sumi. This repository is intentionally separate from the Electron application.

## Product story

The page follows one primary journey:

`事务工作区 → 任务会话 → 人机协作 → Markdown 工作文档 → Skill 交付物 → 知识沉淀`

Ask sumi, automation, Skills, and the knowledge graph are presented as supporting capabilities rather than competing product pillars.

## Development

```bash
npm install
npm run dev
```

Production verification:

```bash
npm run build
```

## Visual direction

- Editorial workbench rather than generic AI gradients
- Warm paper, black ink, and sumi orange
- Restrained motion with `prefers-reduced-motion` support
- Responsive from 360px phones to wide desktop displays
